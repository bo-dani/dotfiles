We use **Original Estimate** in weeks. Usually at the beginning of the project and/or phase.
When the work starts, we use **Story Points** (`1SP == 1D`) and estimate each task under an Epic.

> [!INFO] Uncertainty must be added to the estimation
> If Task A is low effort and it's certain, and Task B is low effort but has some uncertainty, the estimation for B should be higher than A.
